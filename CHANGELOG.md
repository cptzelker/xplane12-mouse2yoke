# Changelog

## v2.2 BETA
- **New optional command: "Mouse2Yoke: release and re-center yoke (optional)".** Assign a key to it (Settings > Keyboard) to let the yoke ease back to neutral, the same as the menu item "Release and re-center yoke". Handy for re-trimming in flight. It has no key by default, and it is listed after the main command.
- **Tiller default changed from 60 to 45 degrees** (`tiller_max_deg` in `settings.ini`). 60 felt too sensitive for most users. You can still change it, for example 30-40 for gentler or 50-60 for tighter turns.
- `settings.ini` reviewed: clearer comments, including a tip for the takeoff and landing roll (hold the left mouse button to steer with the rudder while keeping the mouse centered).
- No other behavior changes.

## v2.1 BETA
- Optional tiller mode for taxiing (nose wheel only), exclusive with flight mode, refused in flight and above 45 kt.
- macOS build (Intel and Apple Silicon).
- `settings.ini` and README fully in English.

## v2.0 BETA
- First release: mouse yoke, left-button rudder, automatic coordinated turns, taxi steering, one-key toggle with hold and no-jump pickup, default yoke box hidden.
